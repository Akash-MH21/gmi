# Troubleshooting Guide

This guide covers common issues when installing or using GMI.

## 1. Installation Issues
- Check that the required dependencies are installed.
- Follow the installation instructions in the main README.
- Read the complete error message if installation fails.

## 2. Configuration Issues
- Check that your configuration values are correct.
- Verify that required environment variables are set.
- Restart GMI after changing configuration.

## 3. Connection Issues
- Check your internet connection.
- Verify that the API endpoint is available.
- Confirm that your authentication credentials are configured correctly.

## 4. Still Having Problems?
If the issue persists, open a GitHub issue. Include the error
message, steps to reproduce the problem, and relevant environment
details. Never share passwords or API keys.
